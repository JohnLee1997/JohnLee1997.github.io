# 隐私政策

**产品：各平台数据统计 Chrome 扩展**  
**最后更新：2026 年 8 月 27 日**

本扩展的唯一用途是：由用户主动发起，对 YouTube 或 X（Twitter）博主在指定日期范围内的公开数据进行统计、展示和导出。

## 我们处理的数据

- **账户信息**：邮箱地址、认证会话、账户套餐和积分余额，用于注册、登录、账户管理和防止未授权使用。
- **查询信息**：博主 ID 或用户名、平台、起始日期、截止日期、汇总统计数据、实际消耗积分和查询时间，用于完成查询、展示查询历史和导出 CSV。
- **当前标签页 URL**：仅在用户打开扩展时于本地读取，用于自动识别 YouTube 或 X 页面中的博主 ID。该 URL 不会单独上传或保存。
- **本地偏好**：深色/浅色主题和登录会话保存在浏览器扩展本地存储中。

## 数据如何使用与传输

- 账户、积分和查询历史存储在 Supabase 服务中，并按登录用户隔离访问。
- 用户主动开始查询时，扩展会将必要的博主 ID、平台和日期范围发送到受认证保护的 Supabase Edge Function。
- Edge Function 再向 YouTube Data API 或 TwitterAPI.io 请求相关公开数据。
- 第三方 API 密钥仅保存在服务器环境变量中，不会发送到扩展或向用户公开。
- 为降低重复查询成本，Twitter 查询结果可能在服务器端缓存最多 24 小时，仅用于相同查询的结果复用。

## 我们不会做什么

- 不会出售、出租或将用户数据用于定向广告。
- 不会读取用户输入的表单内容、Cookie、私信或本扩展功能不需要的数据。
- 不会在用户未打开扩展或未主动发起查询时持续跟踪浏览活动。

## 保存与删除

查询历史保存在用户账户下，用于用户查看和导出。用户可以通过支持邮箱请求访问、更正或删除其账户及查询历史数据。

浏览器中的主题偏好和登录会话，可通过删除扩展或清除扩展数据移除。

## 安全

扩展通过 HTTPS 和 Supabase 身份验证访问服务端接口。积分修改及第三方 API 调用仅在服务端执行，第三方 API 密钥不会存储在扩展前端。
