# 隐私政策

产品：各平台数据统计扩展  
版本：2026-09-01  
最后更新：2026 年 9 月 1 日

本扩展的单一用途是：由用户主动发起，对 YouTube 或 X（Twitter）博主在指定日期范围内的公开数据进行统计、展示和导出，并通过积分与订单机制控制查询成本。

## 我们处理的数据

- 账户与安全数据：邮箱、Supabase 用户 ID、认证会话、账户角色、会员到期时间、积分余额，以及防滥用所需的请求时间、状态和错误记录。
- 查询数据：博主 ID 或用户名、平台、起止日期、公开内容及汇总统计、查询时间、实际消耗积分和缓存命中状态。
- 付款与账务数据：套餐、应付金额、公开收款地址、订单状态、到期时间、交易哈希、付款区块、实际到账金额、充值和退款流水。链上记录可能公开显示付款钱包地址。我们不收集私钥、助记词或钱包密码。
- 当前标签页 URL：仅在用户打开扩展时本地读取，用于识别 YouTube 或 X 页面及候选博主 ID。完整 URL 不作为独立记录保存。
- 本地偏好与确认记录：主题、登录会话，以及已接受的隐私政策和销售条款版本保存在扩展本地存储中。

## 使用目的与服务提供商

- Supabase：注册、登录、数据库、Edge Function、积分结算、订单和必要运行日志。
- YouTube Data API：用户查询 YouTube 时获取公开频道与视频数据。使用本扩展同时受 [YouTube 服务条款](https://www.youtube.com/t/terms)约束；Google 的数据处理见 [Google 隐私权政策](https://policies.google.com/privacy)。
- TwitterAPI.io：用户查询 X（Twitter）时获取公开账号与推文数据；相同查询结果可能缓存最多 24 小时，仅用于复用和成本控制。
- QR Server（api.qrserver.com）：生成付款二维码。编码内容可能包含公开收款地址、X Layer 网络、USDT 合约和精确金额；服务提供商还会接收请求通常包含的 IP 地址和浏览器信息。
- X Layer RPC 与区块浏览器：核验公开 USDT 转账日志、交易哈希、金额、区块和钱包地址。公开区块链记录无法由本扩展删除。

第三方 API 密钥仅保存在服务端环境变量中，不会发送到扩展或展示给用户。

## Chrome Web Store Limited Use

从 Chrome API 获得的数据仅用于提供上述单一用途。我们不会出售或出租数据，不将数据用于广告、信用评估、用户画像或与本扩展无关的目的，也不会允许人工读取数据；但用户明确请求支持、调查安全事件、预防欺诈或法律要求的必要情况除外。

## 保存、删除与退出

- 查询历史通常保留在账户中，直至用户请求删除或删除账户；当前版本不承诺自动到期删除。
- Twitter 查询缓存最多保存 24 小时。
- 订单、积分流水、付款、退款和安全记录会在交易履行、对账、争议处理、防欺诈及法律义务所需期间保存。
- 退出登录会结束当前会话；卸载扩展或清除扩展数据可移除本地主题、会话和政策确认记录，但不会自动删除服务器记录或公开区块链记录。

如需访问、更正或删除账户数据，请从注册邮箱联系支持邮箱。为保护账户，我们可能需要验证身份。

## 安全与权限最小化

扩展通过 Supabase 身份验证访问服务端接口；积分修改、付款核验和第三方 API 调用在服务端执行。我们只申请 `storage` 和 `activeTab` 等实现功能所需的权限，不读取 Cookie、私信、页面表单或持续跟踪浏览活动。任何网络传输均无法保证绝对安全。
