# 隐私政策

**各平台数据统计 Chrome 扩展**  
**最后更新：2026 年 8 月 27 日**

本扩展用于帮助用户统计 YouTube 和 X（Twitter）账号在指定日期范围内的公开数据，并支持查看和导出查询历史。

## 我们收集的信息

为提供服务，我们可能处理以下信息：

- 邮箱地址：用于注册、登录和账户管理。
- 博主 ID 或用户名、查询平台和日期范围：用于完成用户主动发起的数据统计。
- 查询结果、查询时间和积分消耗：用于展示查询历史和导出记录。
- 当前网页地址：仅用于在用户打开扩展时自动识别 YouTube 或 X 页面中的博主账号，不会单独保存或上传。
- 主题偏好和登录状态：用于记住用户选择的深色或浅色界面，以及保持登录状态。

## 我们如何使用信息

我们仅将这些信息用于：

- 提供账号登录、积分管理和数据统计服务；
- 展示和导出用户自己的查询历史；
- 防止滥用、保障账户和服务安全；
- 改进扩展的稳定性和使用体验。

用户主动发起查询时，必要的查询信息会被用于获取对应平台的公开数据。我们不会获取用户的私信、Cookie、表单内容或与本扩展无关的信息。

## 信息共享

我们仅在提供服务所必需的范围内，与账号服务、数据存储服务及公开数据查询服务合作方共享必要信息。

我们不会出售、出租用户信息，也不会将用户信息用于个性化广告、定向广告或营销。

## 数据保存与删除

查询记录会保存在用户账户中，方便用户查看和导出。

用户可通过支持邮箱申请访问、更正或删除账户及查询历史数据。删除扩展或清除浏览器扩展数据后，本地保存的主题偏好和登录状态将被移除。

## 安全

我们采取合理措施保护用户信息，防止未经授权的访问、使用或泄露。

## 政策更新

如果本政策发生重大变化，我们会更新本页的“最后更新”日期。
