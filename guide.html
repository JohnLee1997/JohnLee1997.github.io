1. 认识软件与准备工作

各平台数据统计是 Chrome 扩展，用于查询 YouTube 与 X（Twitter）博主在指定日期范围内发布的公开内容，汇总数据并导出 CSV。它不是自动发帖工具，也不会读取私信或获取私有频道数据。

  1. 准备电脑上的 Chrome 浏览器。通过发布者提供的正式商店入口安装；受邀测试用户按发布者给出的测试包说明安装。本页不提供未经核验的安装包或商店链接。
  2. 打开扩展。点击 Chrome 工具栏的扩展图标，选择“各平台数据统计”；需要时将它固定到工具栏。
  3. 准备可正常收信的邮箱，或 Google 账号。公开使用手册可以在手机查看，但实际数据查询需回到电脑上的扩展完成。

本手册基于扩展 2.1.4 的当前实现。线上可用性取决于服务配置、平台接口和安全限制；请以扩展中的实际提示为准。

2. 注册、验证与登录

使用邮箱注册

  1. 切换到“注册页面”，填写完整邮箱地址。格式检查只判断写法，不能证明邮箱存在或一定能收到邮件。
  2. 设置 10–128 位密码，同时包含大写字母、小写字母、数字和特殊符号。确认密码必须一致；强度条用于辅助检查，不要复用其他网站的密码。
  3. 阅读并同意隐私政策，完成人机验证，再点击“注册”。
  4. 按页面提示检查邮箱，点击确认链接。看到验证成功页后，返回扩展登录；邮箱验证页本身不是数据查询页面。

没有收到邮件？点击“没有收到确认邮件？”或“已经注册但没收到邮件？”，核对邮箱后重新发送。发送后有 60 秒冷却倒计时；若服务返回更长的等待时间，以实际提示为准。也请检查垃圾邮件和邮箱拦截规则。

使用 Google 登录

点击“使用 Google 账号登录”，在授权窗口选择账号并完成登录。请等待回到扩展，不要提前关闭仍在处理的授权窗口。取消或出现错误时，回到登录页根据提示重试。

免费积分在邮箱确认并完成账户激活后可用；仅填写注册表单不等于已经登录，也不等于积分已经到账。

3. 完成第一次数据查询

  1. 进入“数据统计”。先选择 YouTube 或“推特 (X)”。
  2. 检查“博主 ID / 用户名”。在支持的博主页面打开扩展时，会尝试填入候选账号；请核对，不要把显示昵称当成唯一账号。
  3. 选择时间。“快捷天数”可选最近 3、7、14、30 天；“日历范围”先点开始日期，再点结束日期，结束日期包含在范围内。单次范围不能超过一年。
  4. 点击“开始统计”。大范围查询可能出现积分消耗估算确认框；估算不等于最终扣分。等待结果和实际消耗提示，不要连续重复点击。

4. 理解结果与内容分类

结果包含内容合计、浏览或观看总数、评论、点赞、当前粉丝总数以及内容明细。汇总基于本次接口实际返回并纳入统计的内容。

内容分类与口径
平台分类注意事项
X（Twitter）原创发帖、回复、转帖、引用帖按接口提供的类型信息分类，不要将合计直接当成原创数量。
YouTube普通视频、短视频、直播/首播短视频按时长 ≤3 分钟归类，不是 YouTube 官方 Shorts 标记。
  • 粉丝数是当前值：不是所选期间的新增长粉数，也不是该日期的历史快照。
  • 互动数据不是区间增量：不能把某个发布日期区间的观看合计理解为该区间新增观看。
  • “结果可能不完整”需要保留：积分、单次数据量、接口或预算限制可能提前结束查询。不要把部分结果作为全量结果对外使用。
  • 数值可能随时间变化：平台后续互动、删除内容、缓存与接口返回范围都可能造成差异。

5. 查询历史与 CSV 导出

导出本次内容明细

在统计结果下方点击“导出表格 (CSV)”。文件包含内容类型、标题、发布时间、链接、点赞、评论、浏览和当前粉丝量等明细字段。没有内容时无法导出内容明细。

回看与导出历史汇总

  1. 打开“查询历史”，必要时点击“刷新”。
  2. 选择需要的记录，或点击“全选”。
  3. 点击“导出所选”。历史 CSV 包含查询时间、平台、博主、起止日期、内容合计、各类型数量、汇总指标及消耗积分。

两种 CSV 用途不同：结果页导出每条内容，查询历史导出每次查询的汇总。旧记录如缺少后来新增的分类信息，请勿把它当成最新完整统计。

CSV 可用支持该格式的表格软件打开。显示乱码时，使用“从文本/CSV 导入”并选择 UTF-8；导出后请检查日期、数字及列分隔是否符合你的使用需求。

7. 充值与订单处理

⚠ 目前暂不支持 USDT 退款。付款前核对商品、网络、USDT 合约、收款地址和含全部尾数的完整金额；勿多付、少付或重复转账。多付不会额外增加积分。详见销售条款。

  1. 点击“订阅会员或充值积分”，阅读并确认相关条款，选择会员或永久积分套餐。
  2. 订单创建后，检查实际应付金额和倒计时。应付金额含匹配尾数，可能不同于套餐标价；不要自行取整。
  3. 选择二维码模式。Web3 模式供支持 ERC-681 的钱包读取网络、合约、收款地址与金额；交易所模式只包含收款地址，必须手动填写 X Layer、USDT 和完整金额。扫码后仍要核对。
  4. 从钱包或交易所提交转账。确认收款方实际收到的金额与订单一致；如果平台从转账金额扣手续费，先查清实际到账数额再提交。本手册不提供固定收款地址，一律使用当前订单地址。
  5. 提交后等待链上确认和订单更新。自动监听受服务运行状态影响，不保证即时到账；不要因等待而再次付款。
  6. 未及时到账时，在钱包交易记录中复制该笔转账的 TxID，粘贴到订单页并点击“确认到账”。输入框旁的问号也有说明。

“查询充值历史”可查看状态和重新进入未付款订单。取消订单只适用于确认没有已提交或处理中的转账的情况；取消和订单到期都不会撤回链上交易。

如果实际金额、网络或订单状态不符，请保留订单号与交易哈希并联系支持，不要盲目新建订单重新付款。

8. 界面设置与获取帮助

  • 切换语言：使用面板中的“中 / EN”控件切换简体中文或英文。
  • 切换主题：进入“设置 → 界面外观”，选择浅色或深色；偏好会保存。
  • 修改密码：进入“设置 → 账户管理”，按提示输入新密码、确认密码并完成人机验证。
  • 更换使用账户：在设置中退出当前账号，再登录目标账号。查询记录、余额和订单以实际登录账户为准。
